# ТЗ: Поддержка нейроразнообразия в Repetium

> Дополнение к основному ТЗ. Цель — сделать Repetium по-настоящему доступным для пользователей с СДВГ, аутизмом и дислексией. Все фичи проектируются как опциональные настройки, а не отдельные «режимы для инвалидов».

---

## 1. СДВГ (ADHD)

### 1.1 Адаптивный тайминг fade-фазы

**Проблема:** Фиксированная fade-фаза (3 сек) не учитывает состояние пользователя. Человек с СДВГ, отвлёкшийся на секунду, теряет момент — и получает фрустрацию вместо обучения.

**Решение:** Динамическая подстройка длительности fade на основе результатов.

**Требования:**
- Отслеживать процент ошибок за последние 5 заданий
- Если ошибок >60% — увеличить длительность fade на 500ms (максимум до 5000ms)
- Если ошибок <20% — уменьшить на 300ms (минимум до 1500ms)
- Изменения применять плавно, не резко между заданиями
- Хранить текущий тайминг в localStorage, чтобы при возвращении на сайт начинать с последнего комфортного значения
- В настройках: переключатель «Адаптивный тайминг» (вкл/выкл) + ручной слайдер тайминга (1–6 сек) для тех, кто хочет контролировать сам

**Где менять:** компоненты `app/(main)/exercises/g1/page.tsx`, `g2/page.tsx`, `g3/page.tsx` — логика фаз show → dots → empty.

---

### 1.2 Режим фокуса с добровольным таймером

**Проблема:** Людям с СДВГ трудно начать и трудно остановиться. Парадоксально, но мягкий таймер «всего 5 минут» снижает порог входа, а напоминание «можно остановиться» предотвращает гиперфокус с последующим выгоранием.

**Решение:** Опциональный таймер сессии с мягким завершением.

**Требования:**
- Кнопка «Режим фокуса» на экране выбора упражнений
- Варианты: 5 / 10 / 15 минут (визуально — три кнопки, не выпадающий список)
- Во время сессии — тонкая полоска прогресса времени вверху экрана (не навязчивая, цвет `--blue-dim`)
- По окончании таймера — мягкий экран: «Отличная сессия! Вы позанимались N минут. Можно продолжить или отдохнуть.»
- Кнопки: «Ещё 5 минут» / «Завершить сессию»
- Таймер НЕ прерывает текущее упражнение — ждёт его завершения
- Без таймера всё работает как раньше (поведение по умолчанию не меняется)

**Где добавить:** новый компонент `components/FocusTimer.tsx`, интеграция в layout упражнений.

### 1.3 Автоматический выбор следующего упражнения

**Проблема:** 21 группа упражнений на экране выбора — это decision fatigue. Человек с СДВГ может застрять на экране выбора и закрыть приложение, так и не начав.

**Решение:** Кнопка «Продолжить» / «Начать» — система сама выбирает оптимальное следующее упражнение.

**Требования:**
- На главной (`home/page.tsx`) и на экране упражнений — крупная кнопка «Продолжить →»
- Алгоритм выбора: приоритет упражнениям, которые (а) начаты, но не завершены, (б) следующие по прогрессии, (в) давно не практиковались
- Если пользователь хочет выбрать сам — полный список остаётся доступен ниже
- Опционально: краткое пояснение «Сейчас: G2 — буквенные пары. Потому что вы закончили G1 вчера.»

**Где менять:** `app/(main)/exercises/page.tsx`, `app/(main)/home/page.tsx`, новый хук `lib/hooks/useNextExercise.ts`.

### 1.4 Микро-награды

**Проблема:** Отсутствие дофаминовых сигналов при правильных ответах. Для СДВГ-мозга «ничего не произошло» = «скучно» = «закрыть».

**Решение:** Минимальные, ненавязчивые микро-награды за серии правильных ответов.

**Требования:**
- После 3 правильных ответов подряд — мягкая пульсация заполненной буквы (glow эффект, 600ms, цвет `--teal`)
- После 5 подряд — короткий тактильный звук (мягкий «динь», 200ms) — только если звук включён в настройках
- После 10 подряд — анимация «волна» по всем заполненным буквам (1 раз, 800ms)
- НЕ делать: числовой счётчик серии, попапы «Отлично!», конфетти, бейджи
- Серия сбрасывается при ошибке — молча, без акцента на неудаче
- В настройках: переключатель «Микро-награды» (вкл/выкл), по умолчанию — включено

**Где менять:** компоненты recall-фазы в упражнениях, `styles/tokens.css` (новые анимации).

## 2. Аутизм (ASD)

### 2.1 Отключение анимаций

**Проблема:** Анимации shake (при ошибке), popIn, slideIn тостов могут быть сенсорно неприятны. Системная настройка `prefers-reduced-motion` не всегда включена.

**Решение:** Явный переключатель + уважение системной настройки.

**Требования:**
- В настройках: переключатель «Анимации» (вкл/выкл)
- При выключении: все `animation` и `transition` заменяются мгновенными изменениями
- Shake при ошибке заменяется на изменение цвета рамки (без движения)
- Toast-уведомления появляются статично (без slideIn)
- Автоматически выключать анимации, если `prefers-reduced-motion: reduce` в системе
- Fade-фаза упражнений сохраняется (это функциональная часть, не декоративная анимация) — но переход между фазами становится мгновенным

**Где менять:** `styles/tokens.css`, `app/globals.css`, компонент `Toast.tsx`, все файлы упражнений.

---

### 2.2 Превью упражнения (пошаговая инструкция)

**Проблема:** Аутичные пользователи предпочитают точно знать, что произойдёт, до того как это произойдёт. Сейчас упражнение стартует сразу — без предупреждения о механике.

**Решение:** Экран-превью перед первым выполнением каждого типа упражнений.

**Требования:**
- Перед первым запуском каждого типа упражнения (G1, G2, G3 и т.д.) — экран с пошаговым описанием:
  1. «Вы увидите текст на французском»
  2. «Буква [X] будет выделена фиолетовым»
  3. «Через несколько секунд выделение исчезнет»
  4. «Вам нужно вписать пропущенные буквы»
  5. «Если сложно — после 3 попыток появится подсказка»
- Кнопка «Понятно, начать»
- Чекбокс «Больше не показывать для этого упражнения»
- Факт просмотра сохраняется в localStorage
- В настройках: «Всегда показывать инструкцию перед упражнением» (для тех, кому это важно каждый раз)

**Где добавить:** новый компонент `components/ExercisePreview.tsx`, интеграция в каждый `page.tsx` упражнений.

---

### 2.3 Повторное использование текста

**Проблема:** AI-генерированные тексты каждый раз разные — это нарушает предсказуемость. Для аутичных людей работа с знакомым материалом может быть комфортнее и эффективнее.

**Решение:** Возможность повторить упражнение с тем же текстом.

**Требования:**
- После завершения упражнения — кнопка «Повторить с тем же текстом» (рядом с «Новый текст»)
- Последние 5 текстов для каждого типа упражнения сохраняются в localStorage
- На экране выбора упражнения: секция «Знакомые тексты» с возможностью выбрать сохранённый
- В настройках: «По умолчанию использовать знакомый текст» (если доступен)

**Где менять:** API-слой генерации текста, компоненты complete-фазы упражнений, localStorage-менеджер.

---

### 2.4 Режим «без сюрпризов»

**Проблема:** Toast-уведомления появляются неожиданно, случайность в генерации текстов создаёт непредсказуемость.

**Решение:** Единый переключатель, убирающий все неожиданные элементы.

**Требования:**
- В настройках: переключатель «Режим без сюрпризов»
- При включении:
  - Toast-уведомления отключаются (ошибки отображаются inline)
  - Порядок упражнений фиксируется (нет случайного перемешивания)
  - Тексты берутся из фиксированного набора (не AI-генерированные), если доступны
  - Все переходы между экранами — мгновенные
- Режим «без сюрпризов» автоматически включает «Отключение анимаций»

**Где менять:** глобальный контекст настроек, компонент `Toast.tsx`, API генерации текста, навигация.

## 3. Дислексия

### 3.1 Выбор шрифта (OpenDyslexic)

**Проблема:** Режим дислексии меняет только spacing, но не шрифт. Для многих дислексиков специализированные шрифты с утяжелённым низом букв (OpenDyslexic) или усиленным различием b/d/p/q критичны.

**Решение:** Выбор шрифта в настройках.

**Требования:**
- В настройках: селектор шрифта для текстов упражнений
- Варианты:
  - Atkinson Hyperlegible (текущий, по умолчанию)
  - OpenDyslexic (подключить через Google Fonts или self-hosted)
  - Lexie Readable (альтернатива, если лицензия позволяет)
- Шрифт применяется только к текстам упражнений и буквам (`.fr-text`), не к UI
- Переключение шрифта сохраняется в localStorage
- Предпросмотр: при наведении на вариант — пример текста «Bonjour, comment allez-vous?» этим шрифтом

**Где менять:** `styles/tokens.css` (новые font-face), настройки, CSS-переменная `--font-reading`.

---

### 3.2 Настраиваемый порог подсказки

**Проблема:** Подсказка появляется после 3 ошибок. Для дислексика это 3 момента «я не могу» — порог может быть слишком высоким и демотивирующим.

**Решение:** Настраиваемый порог или немедленная подсказка.

**Требования:**
- В настройках: «Подсказка после N ошибок» — варианты: 1 / 2 / 3 / «Показывать сразу»
- «Показывать сразу» = первая буква видна в золотом цвете (`--gold`) с самого начала recall-фазы
- По умолчанию остаётся 3 (текущее поведение не меняется)
- Значение сохраняется в localStorage
- В упражнениях учитывать это значение вместо хардкода `errCount >= 3`

**Где менять:** компоненты recall-фазы (`g1/page.tsx`, `g2/page.tsx`, `g3/page.tsx`), глобальные настройки.

---

### 3.3 Озвучка текста упражнения

**Проблема:** TTS есть только для отдельных букв (по кнопке). Текст упражнения не озвучивается — а для дислексика аудиальный канал одновременно с визуальным критичен для закрепления.

**Решение:** Кнопка озвучки всего текста упражнения.

**Требования:**
- На фазе show (когда текст отображается полностью) — кнопка «Послушать» (иконка динамика)
- При нажатии — TTS читает весь текст на французском
- Во время чтения — текущее слово подсвечивается (караоке-эффект), цвет `--blue-dim`
- Скорость чтения: настраиваемая (0.7x / 1x / 1.3x)
- Кнопка доступна и на фазе recall (чтобы переслушать)
- Использовать тот же API TTS, что и для букв, но с полным текстом
- В настройках: «Автоматически озвучивать текст» — если включено, TTS запускается автоматически на фазе show

**Где менять:** компоненты show-фазы упражнений, API `/api/tts` (расширить для длинных текстов), новый компонент `components/TextTTS.tsx`.

---

### 3.4 Цветное наложение (Color Overlay)

**Проблема:** Многие дислексики значительно лучше читают на цветном фоне. Исследования Irlen Institute показывают, что индивидуально подобранный цвет фона снижает визуальный стресс.

**Решение:** Настраиваемый цветной оверлей для текстов.

**Требования:**
- В настройках: «Цветной фон для текста» — палитра из 6 вариантов:
  - Без фона (по умолчанию)
  - Жёлтый (`#FFF9DB`, opacity 0.7)
  - Голубой (`#DBEAFE`, opacity 0.7)
  - Розовый (`#FCE7F3`, opacity 0.7)
  - Зелёный (`#D1FAE5`, opacity 0.7)
  - Персиковый (`#FED7AA`, opacity 0.7)
- Оверлей применяется только к блоку текста упражнений, не ко всему UI
- Цвет адаптируется для тёмной темы (те же оттенки, но с opacity 0.15)
- Реализация: CSS-переменная `--reading-overlay` на контейнере `.fr-text`

**Где менять:** `styles/tokens.css`, CSS модули упражнений, настройки.

## 4. Общее (для всех трёх групп)

### 4.1 Кнопка «Сделать перерыв»

**Проблема:** Выход из упражнения = «я сдался». Нет промежуточного состояния «я отдыхаю и вернусь».

**Решение:** Явная кнопка паузы с позитивным сообщением.

**Требования:**
- На каждом экране упражнения — кнопка «Сделать перерыв» (иконка паузы, рядом с кнопкой «Пропустить»)
- При нажатии — экран:
  - «Хорошая работа! Вы прошли N заданий.»
  - «Отдохните. Мы сохраним ваше место.»
  - Кнопки: «Продолжить» / «Завершить сессию»
- Состояние (текущее упражнение, текущий текст, позиция) сохраняется в localStorage
- При возвращении — предложение «Продолжить с места, где остановились?»
- Кнопка «Пропустить» остаётся (это другое действие — пропуск конкретного задания)

**Где добавить:** новый компонент `components/PauseScreen.tsx`, интеграция в layout упражнений.

---

### 4.2 Профиль предпочтений при первом входе

**Проблема:** Все настройки спрятаны в разделе Progress → Settings. Новый пользователь не знает, что они существуют, и получает дефолтный опыт, который может быть некомфортным.

**Решение:** Мягкий онбординг с вопросами о предпочтениях (не диагнозах).

**Требования:**
- При первом входе (после регистрации или первого теста) — экран «Настроим под вас»
- Вопросы (не про диагнозы, а про предпочтения):
  1. «Мне нужно больше времени на задания» → адаптивный тайминг, замедленная fade-фаза
  2. «Мне проще, когда всё предсказуемо» → режим без сюрпризов, превью упражнений
  3. «Мне трудно читать обычный текст» → режим дислексии, OpenDyslexic, цветной оверлей
  4. «Мне трудно начать» → режим фокуса с таймером, автовыбор упражнения
- Каждый пункт — toggle, не обязательный
- Кнопка «Пропустить, настрою позже»
- Все выбранные опции записываются в соответствующие настройки
- Можно вернуться к этому экрану из настроек: «Пересмотреть предпочтения»

**Где добавить:** новый экран `app/(main)/onboarding/page.tsx`, интеграция после первого входа.

---

### 4.3 Расширенная панель настроек

**Проблема:** Текущие настройки: тёмная тема, режим дислексии, звук. Этого недостаточно.

**Решение:** Расширить раздел настроек, сгруппировав по категориям.

**Структура:**

**Внешний вид:**
- Тёмная тема (toggle) — уже есть
- Анимации (toggle) — новое
- Цветной фон для текста (палитра) — новое
- Шрифт для чтения (селектор) — новое

**Чтение и восприятие:**
- Режим дислексии: увеличенные интервалы (toggle) — уже есть
- Размер текста (слайдер или S/M/L) — частично есть (adapted mode)
- Автоозвучка текста (toggle) — новое
- Скорость озвучки (0.7x / 1x / 1.3x) — новое

**Упражнения:**
- Адаптивный тайминг (toggle + слайдер) — новое
- Порог подсказки (1 / 2 / 3 / сразу) — новое
- Микро-награды (toggle) — новое

**Комфорт:**
- Режим без сюрпризов (toggle) — новое
- Показывать инструкцию перед упражнением (toggle) — новое
- Звук (toggle) — уже есть

**Где менять:** `app/(main)/progress/page.tsx` (вкладка Settings), новый компонент `components/SettingsPanel.tsx`.

## Приоритеты реализации

### Волна 1 — Быстрые победы (1–2 дня каждая)
1. **Отключение анимаций** — CSS-only, минимальный код
2. **Цветной оверлей** — одна CSS-переменная + UI палитры
3. **Настраиваемый порог подсказки** — замена хардкода на переменную
4. **Кнопка «Сделать перерыв»** — новый компонент, простая логика

### Волна 2 — Средняя сложность (3–5 дней каждая)
5. **Адаптивный тайминг fade** — логика + localStorage
6. **Режим фокуса с таймером** — новый компонент + интеграция
7. **Шрифт OpenDyslexic** — подключение шрифта + UI настроек
8. **Превью упражнения** — новый компонент + условный показ

### Волна 3 — Серьёзная разработка (1–2 недели каждая)
9. **Автовыбор следующего упражнения** — алгоритм + UI
10. **Озвучка текста целиком** — расширение TTS API + караоке-эффект
11. **Повторное использование текста** — кэширование + UI
12. **Режим «без сюрпризов»** — набор фиксированных текстов + глобальный флаг

### Волна 4 — Полировка
13. **Профиль предпочтений (онбординг)** — после реализации настроек
14. **Расширенная панель настроек** — после реализации всех фич
15. **Микро-награды** — анимации + звук + логика серий

## Технические заметки

**Хранение настроек:** Все пользовательские настройки хранить в едином объекте в localStorage (ключ `repetium-preferences`). Структура:

```typescript
interface UserPreferences {
  // Внешний вид
  darkMode: boolean
  animations: boolean
  readingOverlay: 'none' | 'yellow' | 'blue' | 'pink' | 'green' | 'peach'
  readingFont: 'atkinson' | 'opendyslexic' | 'lexie'

  // Чтение
  dyslexiaMode: boolean
  autoTTS: boolean
  ttsSpeed: 0.7 | 1 | 1.3

  // Упражнения
  adaptiveTiming: boolean
  manualFadeDuration: number | null  // null = адаптивный
  hintThreshold: 0 | 1 | 2 | 3      // 0 = показывать сразу
  microRewards: boolean

  // Комфорт
  noSurprises: boolean
  showPreview: boolean
  sound: boolean
}
```

**CSS-стратегия:** Добавить классы на `<body>`:
- `body.no-animations` — отключает все анимации
- `body.no-surprises` — отключает тосты, фиксирует переходы
- `body.overlay-yellow`, `body.overlay-blue` и т.д. — цветные оверлеи
- `body.font-opendyslexic` — шрифт

**Доступность:** Все новые элементы должны иметь ARIA-атрибуты. Все настройки — `role="switch"` с `aria-checked`.
